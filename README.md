## Welcome to Chatty

Chatty is a real-time messaging app which has the following functionality

- Create user account
- Users can upload their own profile picture
- Message any other user on the platform
- Save chat history
- Responsive


The technology used for this app

- React & Tailwind CSS
- Node & Express
- Prisma
